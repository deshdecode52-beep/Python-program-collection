# Python Programs Collection

This repository contains three Python programs demonstrating basic programming concepts.

## Programs Included

### 1. Factorial of a Number

Calculates the factorial of a non-negative integer using a loop.

**Example:**

```text
Input: 5
Output: Factorial of 5 is 120
```

### 2. Fibonacci Series

Generates the Fibonacci sequence for the number of terms entered by the user.

**Example:**

```text
Input: 7
Output: 0 1 1 2 3 5 8
```

### 3. Structure-to-Dictionary Conversion

Uses Python's `dataclass` and `asdict()` to represent structured student information and convert it into a dictionary.

**Example:**

```python
{'name': 'Alex', 'age': 17, 'course': 'MBA'}
```

## Requirements

* Python 3.7 or later
* No external libraries required.

## How to Run

Open a terminal in the project directory and execute each program separately:

```bash
python factorial.py
python fibonacci.py
python structure_to_dictionary.py
```

If your system uses `python3`, replace `python` with `python3`.

## Concepts Demonstrated

* Variables and data types
* User input and output
* Conditional statements
* Loops
* Classes and dataclasses
* Dictionary conversion

## Conclusion

These programs demonstrate fundamental Python concepts through mathematical calculations, sequence generation, and structured data conversion.
